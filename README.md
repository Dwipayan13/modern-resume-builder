# Modern Resume Builder

A professional resume builder web application that helps users create beautiful, ATS-friendly resumes in minutes.

## Features

- 📝 Easy-to-use form interface
- 👀 Real-time preview
- 📱 Responsive design
- 💾 Save multiple resumes
- 📊 ATS score analysis
- 📄 Export to PDF
- 🎨 Professional styling
- 🔄 Dynamic sections for experience, education, projects, and more

## Technologies Used

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (Vanilla)
- jsPDF for PDF generation
- html2canvas for preview capture
- Font Awesome for icons

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/yourusername/modern-resume-builder.git
```

2. Open `resume-editor.html` in your web browser

## Usage

1. Choose your profile type (Fresher/Experienced)
2. Fill in your personal information
3. Add your professional summary
4. Input your skills, experience, education, and other details
5. Use the real-time preview to check your resume
6. Download as PDF or save for later editing
